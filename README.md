# Chapter 3: Scalar and Vector

An interactive, mobile-friendly notebook based on the original Chapter 3 Scalar and Vector lecture notes.

## Features

- All 76 original pages
- Search and section navigation
- Bookmarks and lecturer notes saved in the browser
- Light and dark themes
- Presentation and fullscreen modes
- Mobile-responsive layout
- Original PDF download

## Project files

- `index.html` — page structure
- `styles.css` — design and responsive layout
- `data.js` — notebook content and page images
- `script.js` — interactions and controls
- `assets/` — downloadable original PDF

## Run locally

Open `index.html` in a browser, or run:

```bash
npm start
```

Then visit `http://localhost:8000`.

## Publish with GitHub Pages

Upload the contents of this folder to the root of a GitHub repository. In the repository, open **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
